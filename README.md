# DojoCore

DojoCore is a web application for managing martial arts clubs and their communities. It provides tools for organizing gyms, athletes, coaches, managers, and training groups, with dashboards for viewing club and membership information.

The application also supports competition result imports from spreadsheets, competition result browsing, and maps for viewing gym and member locations. Administrative features include menu and translation management.

## Features

- JWT-based registration, login, and authenticated access
- Gym, athlete, coach, manager, and group management
- Membership and dashboard statistics
- Competition spreadsheet imports and results
- Maps for gyms, athletes, coaches, and managers
- Admin tools for menus and translations

## Tech stack

- ASP.NET Core API on .NET 10
- React web client built with Vite and Material UI
- PostgreSQL data access using Dapper
- Excel spreadsheet parsing for competition imports
